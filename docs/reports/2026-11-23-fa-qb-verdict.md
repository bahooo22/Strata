# FA-QB: prompt-attention с кодами K/V вместо fp16-стенда — вердикт NULL (2026-11-23)

Стенд: strata-q36 0.2.20-форк, RTX 3060 Ti 8 ГиБ, KAT-Coder-V2.5 IQ4_XS, KV q4_0, `--fa -2 --fa-tile 4`.
Носители: `glm/scripts/fa_qb_apply.py` (генератор/установщик, verify-math и selftest зелёные),
`glm/2026-11-23_session/fa-quantb/` (превью), логи `glm/2026-11-23_session/faqb-*.log`.

## Идея и потолок

FA (`q36_fa.cuh`) перед ядром раскладывает KV в fp16-стенд `k16/v16`; идея QB — читать K/V кодами прямо
в ядре (как FDEC), минуя стенд. Стенд — память (2048 Б на токен = 328 МБ на 160k), не время: конверсия
17,5 мс из 1939 мс attn на 16k. Потолок выгоды — доля фазы K в профиле FA:

| конфигурация | K | score | softmax | pv | pp |
|---|---|---|---|---|---|
| 96k tile4 | 14,0–15,0 % | 30,8–31,2 % | 23,8–24,0 % | 30,4–30,8 % | 1090,4 |
| 160k tile4 | 14,1 % | 31,2 % | 23,6 % | 31,1 % | 859,7 |
| 160k tile0 (4x32) | 20,1 % | 20,5 % | 38,7 % | 20,7 % | 748,5 |

Минус 47 % байт K (q8) / 72 % (q4) от 14 % даёт 6,6–10 % pp в идеале, минус ALU на распаковку.
Дефолт tile0 на исправленном FA на 13 % медленнее tile4 (748,5 против 859,7) — таблица 22.11 снята
до починки FA.

## Замер (патч применён, opt-in STRATA_Q36_FA_QB=1)

| конфигурация | pp (bench 0/1) | tg200 (bench 0/1) |
|---|---|---|
| 160k QB=0 (гейт) | 861,2 / 860,7 | 12,9 / 13,3 |
| 160k QB=1 | 857,4 / 856,2 | 12,7 / 13,3 |
| 160k QB=1, повтор | 857,4 / 856,3 | 13,0 / 13,4 |
| 32k QB=0 (гейт) | 1485,2 / 1472,2 | 16,9 / 30,6 |
| 32k QB=1 | 1482,6 / 1469,7 | 17,1 / 30,9 |

Выигрыша нет: 160k — минус 0,5 % pp стабильно (два независимых прогона), 32k — в шуме (−0,2 %),
tg без изменений. Потолок 14 % не реализовался: ALU-распаковка (на 8 значений q8 — 1 LDG.64 +
2 byte_perm + 2 hsub2 + 1 LDG.16 + 2 hmul2) съедает экономию байт.

## Решение

Патч откачен (`q36_engine.cu` возвращён к `8e2f2af94`, `q36_fa_qb.cuh` удалён), дерево пересобрано
(rc=0). В дерево ничего не добавлено: направление закрыто замером. Генератор и превью остаются вне
дерева как носители. Аллокация fp16-стенда не тронута — она держит откат cuBLAS и CHECK.
