# Прогресс ядра Страты: две базовые точки и рабочие окна 64k-160k (09.11.2026)

Зачем: чтобы разрыв между «как было до наших правок» и «что работает сейчас» читался как число, а не
как прилагательное. Обе базовые точки стоят в одной таблице рядом с рабочими рядами: база форка
`146df3c4` (сток, до наших правок) и наш собственный старт 01.11 (`170.5 pp` на 64k). Диаграмма —
`docs/assets/kernel-progress.svg`.

## 1. Чем меряется

Все ряды сняты на одном стенде (RTX 3060 Ti 8 ГБ с анлоком, 31,87 ГиБ RAM, модели на SSD), одним
промптом `master.txt`, temperature 0, greedy, ответ 256 токенов, если в строке не сказано иное.

| ряд | сборка | база / флаги |
| --- | --- | --- |
| Страта сток | сборка `engine-stock` | `146df3c4`, KV остаётся fp32 |
| Страта форк 01.11 | `engine/build/strata-q36.exe` | KV q4_0, без super-chunk и FA |
| Страта форк 05.11 | то же дерево + super-chunk | `STRATA_Q36_SUPER_CHUNK=4`, MTP 0 |

## 3. Что и сколько дало

- **KV q4_0 вместо fp32 — это про окно, а не про скорость.** У стока KV по умолчанию fp32
  (~45 КБ/токен), поэтому 8 ГБ кончаются ровно на 32k. q4_0 снимает границу: те же 8 ГБ держат 160k.
  pp на лесенке стока почти не двигается (109.6-125.9), то есть окно куплено не ценой prefill.
- **Chunk prefill 2048** против дефолтного: 170.5 → 1026.8 pp на 64k. Оговорка: тот прогон шёл с MTP 2
  и tg 21.7 против 33.4, поэтому сравнивать надо pp, а не «всё сразу».
- **super-chunk N=4** против N=1: +25 % pp на 64k, +28 % на 96k, +21-22 % на 128k, проверено на двух
  моделях; подробности — [super-chunk.ru.md](super-chunk.ru.md).
- **Flash attention** поверх super-chunk: 913.8 → 1504.0 (+64,6 % на 64k), 1024.0 → 1308.9 (+27,8 % на
  96k), 813.4 → 1091.9 (+34,2 % на 128k); гейты — [fa-attention.ru.md](fa-attention.ru.md).
- **Цена MTP 2** видна внутри одного ряда: на 64k 1504.0 → 1350.9/1352.6 pp при tg 16.4/16.9. Точка 80k
  рабочего ряда (1253.6) снята профилем с MTP 2, поэтому она ниже 96k — это не деградация окна.
- **160k** до FA существовал только как needle-серия (TTFT 246-248 с при промпте ~150k); теперь это
  замерянная точка prefill — 959.9 pp / 13.6 tg.
- У llama форка 160k на 8 ГБ не поднялся, поэтому рабочий ряд Страты — единственная линия с пятью
  окнами.

## 4. Качество на больших окнах

Большие окна подтверждены не только скоростью: иглы с FA по умолчанию дают 7/7 full и 7/7 number на 96k
и на 160k, на 128k — 5/7 full при 7/7 number. FA не ухудшил поиск иглы ни на одном окне.

## 5. Оговорка по маршруту: окно доступно не каждому кванту

UD-IQ3_S на 64k в Страте читает промпт через native grouped kernels: 64 660 токенов за 1 276 073 мс =
50.7 tok/s при decode 17.8 tok/s. llama на той же модели и окне даёт 1106.49 pp на 64 641 токене —
разница в 21.8 раза, хотя decode паритетный (17.8 против 17.29 tg). То есть «окно 160k доступно» не
значит «на любой модели»: для IQ3-квантов prompt-путь Страты идёт медленными ядрами, и сетка по моделям
обязана это показывать числами.

заметка — опубликованная сводка тех же чисел.
