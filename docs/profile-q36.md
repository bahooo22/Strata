# Профилировщик q36 (`STRATA_Q36_PROFILE=1`)

Сборка `e1002945`; профилировщик в `src/qwen35/q36_engine.cu` (в `layer()` вокруг миксера
и MoE; `cudaEvent` + синхронизация только при включённом env). Вывод — в `--bench-pp/tg`:
`profile: attn .. ms, gdn .. ms, moe .. ms` (stderr), счётчики обнуляются после каждого rep.

## CPU-потоки пула (KAT 16k, pp 8192 / tg 64, reserve 512)

| `--pool-workers` | pp | tg | CPU-пул, с |
| ---: | ---: | ---: | ---: |
| 3 (default) | **336.9–345.9** | **25.5–26.0** | 5.0 |

3 воркера (default на 4 физических ядрах) — оптимум; 4 и 8 хуже: потоки делят ядра и

## Attention score buffer (KAT 16k, reserve 512)

| `kAttScoreFloats` | слотов | pp | tg |
| ---: | ---: | ---: | ---: |
| 64M (256 MB, default) | 36 | **309–339** | **22.5–26.3** |
| 32M (128 MB) | 39 | 243–308 | 17.3–22.7 |

Меньше буфер → +3 слота экспертов, но attention медленнее настолько, что общий pp/tg
падает. Оставлено 64M.

## Reserve (KAT 16k, pp 8192 / tg 64, cpu 4)

| `--vram-reserve-mib` | слотов | pp | tg | CPU-пул, с |
| ---: | ---: | ---: | ---: | ---: |
| 768 | 32 | 281.0–298.3 | 21.3–24.0 | 5.6 |
| 512 | 36 | **309.2–338.6** | **22.5–26.3** | 5.1 |
| 256 | 40 | 285.3–315.1 | 24.0–25.2 | 5.1 |

Меньше резерв → больше слотов экспертов в VRAM → быстрее и prefill, и decode (256 и 512
в пределах шума, оба лучше 768). Для 16k выбран 512 (36 слотов, запас на MTP). С MTP2 и
reserve 512: pp 316.4–331.8, tg 23.7–26.5 — профиль 16k переведён на 512.

На 80k (chunk 1024, MTP 2) наоборот: reserve 768 — 275.7/16.4, reserve 512 — 256.7/16.9;
prefill падает на 7 %. Для 80/96k запас под staging/KV нужен — там 768/1024; уменьшать
резерв только на коротких окнах.

## hybrid-rows (KAT 16k, chunk 1024)

`--hybrid-rows 1024` переводит prefill-чанк с PCIe-стриминга на слоты + CPU-пул: 4 потока
не справляются — prefill 8192 не завершился за ~5 минут (при default 128/streamed — ~30 с
на повтор). Оставить default 128.

## Ограничение

Профиль виден в `--bench-pp/--bench-tg` и в serve-DONE: при `STRATA_Q36_PROFILE=1` движок
после строки DONE печатает в stderr (лог движка) `profile: attn … ms, gdn … ms, moe … ms`
и обнуляет счётчики — доля каждого запроса. Без env синхронизаций нет.

Размер attention-буфера — флаг `--att-mb` (64…512; по умолчанию 256 МБ), переменная
`STRATA_Q36_ATT_MB` остаётся запасным путём; меньше буфер — больше слотов экспертов в VRAM.
